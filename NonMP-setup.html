AnaBodhi

The direct Mac helper is ready. Keep it open while using the plugin.

  1. Open RemNote → Settings → Plugins → Build → Develop from localhost.
  2. Enter http://localhost:27183 and allow access to the plugin’s collection.
  3. Close Settings, open AnaBodhi and press Sync.

Disable the older PYQ Sync plugin. Create and edit questions in Google Sheets. Extra cards created inside the managed RemNote collection are moved to Trash; trashed source cards are recreated when their completed question remains in Sheets.

This direct helper is for Mac. Use the reviewed marketplace plugin for mobile syncing later.
